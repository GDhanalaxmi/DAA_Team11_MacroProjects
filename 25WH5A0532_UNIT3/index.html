About This Project

This project demonstrates how Dynamic Programming can be used to solve the Traveling Salesperson Problem (TSP) for four cities.

Enter the travel distances between cities and click Update Matrix & Solve to calculate a new optimal route.

1. Distance Matrix

Enter the distance between each pair of cities. The matrix is symmetric, so changing one distance automatically represents the same distance in the opposite direction.

Note: Diagonal values are fixed at 0 because the distance from a city to itself is 0.

5. Optimal Solution

How Dynamic Programming Solves TSP

The algorithm starts from city A and gradually considers larger subsets of cities.


For every state, the algorithm checks possible previous cities and calculates the travel cost.


The minimum cost is stored for each state, avoiding repeated calculations.


DP State: dp[visited set][current city]


After all four cities are visited, the algorithm returns to city A and calculates the minimum possible total cost.
